# Encoded image corpus

These are real encoded PNG/JPEG/WebP files generated from synthetic pixels, plus explicitly named malformed/unsupported cases. No private or externally licensed photos are included. Source and generated bytes are distributed under Remage's MIT license.

Regenerate with node scripts/generate-web-fixtures.mjs. The manifest.json file records each file's purpose, byte length and SHA-256; review changes rather than silently replacing release evidence. Tests must independently decode supported outputs and distinguish expected rejection from a successful transformation.

This corpus covers hidden transparent RGB, partial alpha, palette/grayscale, progressive JPEG, EXIF orientation, embedded ICC, CMYK, APNG, 16-bit PNG, truncated headers, oversized dimensions and efficient JPEG/WebP sources. Adversarial parser cases and lifecycle failures also require automated constructed-input tests; this corpus alone does not establish device qualification or strict optimization.
